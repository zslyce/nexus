# WP-07 · Daemon, IPC and CLI
**Agent:** nexus-interface · **Writes:** `src/daemon/**`, `src/ipc/**`, `src/cli/**`, `src/index.ts`, `tests/unit/{daemon,ipc,cli}*`
**Read:** `src/contracts/api.ts`, ADR-002/004, docs 05 and 06.

## Deliverables
- Module composition, lifecycle, signals, idle shutdown, rotated log.
- IPC server and client for `BridgeApi` (including SSE `subscribe` and cancelling a `wait` when the client disconnects).
- Single instance, token, `daemon.json` written atomically, recovery from a stale record.
- On-demand, detached daemon startup.
- CLI from 05. `monitor` loads `src/dashboard` through `runDashboard(api: BridgeApi, options)`.

## Acceptance
- Two simultaneous starts leave a single daemon.
- Wrong token → 401.
- **R1:** Windows test: launch the daemon from a parent process, kill the parent's tree (`taskkill /T /F`) and also close stdin the way Claude Code does; document what survives and fix it if the daemon dies.
