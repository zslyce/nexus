- Plugin structure from 05, commands with `allowed-tools` limited to the tools they need, and `$ARGUMENTS`.
- `model` and `effort` of each skill according to the table in docs 05, comparing the cost of switching models with `context: fork`.
- All plugin text in English.
- Resolve ADR-010 and update it.
- Reproducible install and uninstall on Windows. Do not edit `~/.claude/settings.json` or global configuration without the user's confirmation.

- With the plugin loaded, the MCP server connects and exposes the 8 tools (check it, e.g. with `claude --plugin-dir ./plugin mcp list`).
- Check which short command names work and document it.
