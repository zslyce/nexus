# WP-02 · OpenCode gateway
**Agent:** nexus-opencode · **Writes:** `src/server/**`, `tests/unit/server*`, `tests/integration/server*`
**Read:** `src/contracts/gateway.ts`, all of docs 04, ADR-001/008.

## Deliverables
- `opencode-client.ts`, `connection.ts`, `server-manager.ts` implementing `OpenCodeGateway`. The only folder that imports `@opencode/client`.
- Connection: `discover()`; if nothing is found and `autoStart`, `ensure()` with no version requirement and a command that works on Windows. Rediscover after a transport failure (the port changes on restart).
- Error translation to `NexusError` / `ErrorInfo` (with `transient`).
- `listModels` retries if the result is empty.
- `subscribe` that honors the closing contract (resolve R2; if the client cannot, implement the SSE reader with `fetch` + `AbortController` and justify it).
- Detect a silent stream (keepalive/activity) and end it so the caller reconnects.
- `getOutput` from the messages after `promptMessageId`.

## Acceptance
- Unit tests against a fake HTTP server (use the fixture OpenAPI): 401, network down, 404, SSE cut midway.
- Integration without inference: info, Go models, create/get/delete a session in a temporary folder, repeat the creation, open and close `subscribe` and check the process exits by itself.
- Do not stop or restart the user's service. Test startup (R7) only with an isolated registration file; if that is not possible, report it as not verified.
