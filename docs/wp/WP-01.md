# WP-01 · Config and utilities
**Agent:** nexus-core · **Writes:** `src/config/**`, `src/utils/**`, `tests/unit/config*`, `tests/unit/utils*`
**Read:** `src/contracts/{common,config,agents}.ts`, `nexus.config.json`, docs 05 (Configuration) and 06.

## Deliverables
- `loadConfig(workspace): NexusConfig` with defaults, strict zod validation and errors that name the key. Computes `workspace` (realpath), `stateDir`, `opencodeId` and `source`. Copies `agents.<n>.from` into `AgentDefinition.from`; with `from`, `description` and `systemPrompt` may be omitted.
- Logger to stderr/file implementing `Logger`, with levels and recursive redaction of sensitive keys and `Authorization` headers.
- Transient error classification on top of `NexusError` (already defined in `contracts/common.ts`).
- Path guard: returns normalized relative paths or throws `PATH_OUTSIDE_WORKSPACE`.
- ID generators (`tsk_`, `ses_nexus`, `msg_nexus`), stable idempotency key, capped exponential backoff with injectable jitter.

## Acceptance
- Path tests: `..`, absolute outside, UNC, another drive, escaping junction (Windows), upper/lower case, not-yet-existing file inside the workspace.
- The real `nexus.config.json` loads without errors.
- A test proves that no sample secret appears in the logger output.
