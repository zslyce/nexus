# WP-03 · Storage
**Agent:** nexus-core · **Writes:** `src/storage/**`, `tests/unit/storage*`
**Read:** `src/contracts/{store,tasks,events}.ts`, docs 03 and 06.

## Deliverables
- `database.ts` (`node:sqlite`, WAL, `busy_timeout`, foreign keys), `migrations/`, `repositories/`, `Store` implementation.
- Tables: tasks, dependencies, sessions/attempts, events, results (including errors and timings), snapshot of the agent used by each task.
- Dedupe by `event_id`; auto-incrementing `seq`, never reused.
- `prune` according to `RetentionPolicy`; reclaim space (`auto_vacuum` or an occasional `VACUUM`).
- Nestable transactions, or a clear error.

## Acceptance
- Reopening the database keeps everything; migrating twice is harmless.
- `prune` never touches active tasks or their dependencies.
- A corrupt or future-version database raises an explicit error without deleting data.
